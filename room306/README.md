306 號房的菸味
==============

喵上原市，一棟只租給獸人的老公寓。

房東把 306 號房五個住戶的電子鎖密語雜湊起來存著，四顆種子寫在牆上的
便條紙上。那張紙被ヤニ子拿去捲菸了。

他還留著當年產表的程式，和一份算好的表。


檔案
----

gen_table.py    當年產出下面三個檔案的程式
shadow.txt      五個住戶的密語雜湊
nyan.tbl        那份算好的表
flag.enc        加密的 flag
note.png        牆上那張便條紙
note.txt        便條紙的純文字版


房東的話
--------

「那四個數字啊……都是這棟樓的房客。

三個是年紀。剩下那個是有人在 YouTube 那種網站上開了頻道，訂閱她的人數，
整天關在房裡打電動直播，吵死了。

誰是誰、什麼順序，你自己去問他們，我懶得記。

反正你要是填對了，那張表自己會告訴你。」
